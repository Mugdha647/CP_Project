# CP-Journey

A learning platform for competitive programming — being built in phases.

## Phase 1 (current)

- React + Vite project setup
- `Navbar` and `Footer` components
- `Home` page with a hero section
- Global design tokens (colors, type) in `src/index.css`

## Run it

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

## Build for production

```bash
npm run build
```
